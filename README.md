# Cute Clock

A tiny always-on-top desktop clock + countdown timer with a unicorn. Windows only, nothing to install.

## Run
`git clone <repo-url>`, then double-click **start.bat**.

## Use
- **Drag** anywhere to move it; **drag the bottom-right corner** (shows on hover) to resize
- **clock / timer switch** (top right) toggles modes
- **Timer:** click the time to type one (`25` = minutes, `5:30`, `1h30m`, or `+5` to add), or use -1 / +1 / +5, mouse wheel, play/pause, reset
- The timer keeps running in the background while you view the clock. The bar at the bottom slowly fills with gold as time passes, and the alarm chimes 3 times at zero, then keeps flashing until you tap it.
- **Right-click** for 24h / seconds / date / always-on-top / themes / quit

Position, size and settings are remembered (stored in %APPDATA%\cute-clock).
